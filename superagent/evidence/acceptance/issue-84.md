## 背景
恢复与故障注入是确定性编排的可信度核心。继承 HARNESS_STANDALONE §8 与 T21/T22/T24。

## 任务
- [ ] 四个断点注入：发送前、发送后响应前、响应后绑定前、gate 完成后事务前
- [ ] uncertain 对账：经 thread/read 等公开接口确认；无法证明是否执行则等待处理，不自动重放
- [ ] 独占 resume：租约+包/输入/工作目录/artifact 摘要核对；原成功节点仅产物匹配且依赖未变才复用
- [ ] 旧连接审批 request ID 不回放；恢复时重新确认等待状态
- [ ] 引擎崩溃、慢消费者、超长行、大日志、未知事件/请求测试；不得静默丢终态
- [ ] 中断运行不能仅因 SessionEnd 标记成功

## 验收
崩溃恢复不重复已确认成功节点；全部故障测试通过；非幂等节点不盲目重试。
